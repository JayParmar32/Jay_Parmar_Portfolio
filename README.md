# Jay Parmar Portfolio

A responsive personal portfolio website built using:

- HTML5
- CSS3
- JavaScript
- Bootstrap 5

## Folder Structure

```text
jay-portfolio/
├── index.html
├── about.html
├── skills.html
├── education.html
├── projects.html
├── certifications.html
├── contact.html
├── lab.html
├── README.md
├── css/
│   └── style.css
├── js/
│   ├── script.js
│   └── lab.js
├── images/
│   └── profile-placeholder.svg
```

## Frontend Setup

Each portfolio area is available as its own page and shares `css/style.css` and `js/script.js`.
Open `index.html` directly in a browser or serve the folder with any static web server.
The contact form currently provides a frontend-only confirmation and does not store messages.
The `lab.html` page demonstrates multimedia, Canvas/SVG graphics, Bootstrap layout, JavaScript events,
client-side registration validation, and a JSON API request.
